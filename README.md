## Sobre o projeto

Este repositório contém o portfólio pessoal de Gabriel Rodrigues Silva, estudante de Engenharia da Computação no CEUB e desenvolvedor web/back-end em formação.

O site foi pensado para apresentar uma trajetória verificável: formação, experiência prática, projetos autorais, capacidades técnicas e canais profissionais. A narrativa segue uma linha do tempo editorial, conectando estudo, operação e construção de produtos digitais.

> O objetivo é mostrar evidências de aprendizado e capacidade de construção antes de pedir contato.

## O que o visitante encontra

- apresentação profissional e foco de atuação;
- trajetória acadêmica e experiência na IPE Trading;
- projetos Organized Hub e Gabriel AI Hub — Roteador;
- competências organizadas por contexto de uso;
- currículo profissional em PDF;

## Projetos em destaque

### Organized Hub

Produto digital para organizar estudos, carreira, projetos e agentes especializados em um único espaço.

**O que demonstra:** desenvolvimento de interface, organização de informação, definição de fluxos e conexão entre diferentes áreas de trabalho.

**Tecnologias e conceitos:** desenvolvimento web, TypeScript, banco de dados e automação.

[Explorar projeto relacionado no GitHub →](https://github.com/Gaba061/projeto-1-pg2)

### Gabriel AI Hub — Roteador

Fluxo de automação em n8n que encaminha mensagens para agentes especializados e preserva o contexto de cada usuário.

**O que demonstra:** integração de serviços, validação de requisições, roteamento de agentes, histórico idempotente e memória persistente isolada.

**Tecnologias e conceitos:** n8n, webhooks, contratos de API e automação com IA.

[Conhecer o fluxo →](https://gaba061.app.n8n.cloud/workflow/Gd3TgFC1BhBpGtCD)

## Executar localmente

O projeto é estático e não exige banco de dados ou instalação de dependências.

Com Python:

```powershell
python -m http.server 8000
```

Depois, abra <http://127.0.0.1:8000>.

Também é possível abrir `index.html` diretamente no navegador ou usar a extensão Live Server no VS Code.

## Publicação

A pasta pública pode ser hospedada em qualquer serviço de arquivos estáticos. O projeto também contém configurações de apoio para Sites e Oracle Cloud em versões locais de desenvolvimento.

Antes de publicar uma nova versão, confira:

1. se o currículo está atualizado;
2. se os links externos continuam válidos;
3. se o vídeo carrega em desktop e celular;
4. se as informações profissionais continuam factuais;
5. se o domínio e a audiência da hospedagem estão corretos.
